## اجرا
1. پوشه را در Android Studio باز کنید (File > Open) و Sync کنید.
2. (اختیاری) فونت و عکس‌های نمونه را طبق `app/src/main/assets/README.txt` بگذارید.
3. برای خروجی نهایی: **Build > Generate Signed APK > release** (نسخه debug بزرگ‌تر است و برای قضاوت حجم ملاک نیست).

## چه چیزی در v3.2.0 جدید است (موتور تم سایت — با بررسی گیت‌هاب/ردیت/ایکس)
- **موتور تم سایت (`ThemeEngine.kt` + توسعه `ColorDetector.kt`):** وقتی لینک سایت را
  می‌دهید، اپ فقط یک رنگ برند پیدا نمی‌کند — یک **تم کامل** می‌سازد: رنگ اصلی، فرعی،
  تاکید، گرادیان پس‌زمینه استودیو و رنگ متن روی هرکدام (با کنتراست WCAG، هدف ۴٫۵).
  زیر فیلد لینک، سه چیپ «اصلی / فرعی / تاکید» با کد رنگ نشان داده می‌شود (با لمس
  هرکدام، همان رنگ به‌عنوان رنگ برند انتخاب می‌شود) و پس‌زمینه حالت برند، **گرادیان
  واقعی سایت** می‌شود (اگر سایت گرادیان نداشت، گرادیان از رنگ‌های تم ساخته می‌شود).
- **روش (با الهام از dembrandt در گیت‌هاب، سازگارشده با موبایل — بدون مرورگر):**
  dembrandt تم سایت را از استایل‌های محاسبه‌شده DOM با Chromium می‌خواند؛ روی گوشی
  مرورگر نیست، پس همان ایده با تحلیل CSS پیاده شد: گرادیان‌های برند
  (`linear/radial-gradient`)، پس‌زمینه بدنه سایت (روشن/تیره بودن تم)، رنگ دکمه/لینک
  (نقش تاکید)، متغیرهای CSS برند، theme-color، manifest و رنگ غالب لوگو — همه با
  امتیازدهی چندمنبعی مثل قبل. استخراج تم فقط به اینترنت برای گرفتن HTML/CSS سایت
  نیاز دارد؛ ساختن تم کاملاً روی گوشی و آفلاین است؛ بدون سرور، بدون کلید API.
- **صادقانه درباره «AI تم»:** برای استخراج تم سایت، مدل عصبی استانداردی روی گوشی
  وجود ندارد — این کار ذاتاً تحلیل پالت است، نه تشخیص سوژه؛ پس موتور تم یک
  تحلیل‌گر پالت هوشمند است (خوشه‌بندی + هارمونی رنگ + کنتراست)، نه یک مدل ML.
  **مدل‌های جدیدتر جداسازی هم بررسی شدند و عوض نشدند:** ormbg (ISNet، ‏۱۰۲۴×۱۰۲۴،
  ‏۲۴۶ میلی‌ثانیه روی Pixel 8a) ‏۱۷۶ مگابایت است، BiRefNet نسخه سبک ‏۲۲۴ مگابایت،
  RMBG-2.0 لایسنس تجاری می‌خواهد (CC BY-NC) — هیچ‌کدام در APK جا نمی‌شوند؛ U2NetP
  با ۴٫۵۶ مگابایت همچنان انتخاب درست برای باندل است. (نکته بازار: remove.bg از
  اول دسامبر ۲۰۲۶ بسته می‌شود و به Canva می‌رود؛ آفلاین و رایگان بودن آنیک حالا
  ارزشش بیشتر است.)
- **ظاهر عوض نشده:** همان یک صفحه، همان ترتیب؛ هیچ بخش و صفحه جدیدی اضافه نشده و
  اسکرول بیشتر نشده است — فقط محتوای همان ردیف لینک سایت و همان حالت برند غنی‌تر شد.

## موتور هوش مصنوعی — چطور انتخاب و تایید شد (v3.1)
- **ران‌تایم: LiteRT 1.4.0** (`com.google.ai.edge.litert:litert` + `litert-api`، از مخزن
  گوگل). TFLite قدیمی 2.16.1 فایل `.so` با تراز 4KB داشت و خطای 16KB می‌داد؛
  2.17.0 روی Maven اصلاً AAR ندارد (فقط یک POM تغییرمسیر به LiteRT). فایل `.so`
  arm64 نسخه LiteRT 1.4.0 با **readelf** بررسی شد: هر سه سگمنت LOAD تراز
  **0x4000 (16KB)** دارند — پس خطای 16KB برنمی‌گردد. `litert-api` هم لازم است
  (بدون آن در اجرا خطای InterpreterFactoryImpl می‌دهد).
- **مدل: U2NetP** (`assets/models/u2netp.tflite`، ‏۴٬۵۶۲٬۱۲۸ بایت، SHA-256:
  `1bd35cc6a71451df7a2c6d98ccda17f6b8c397624192436d50e5b0fc62b5b746` — با
  نسخه منتشرشده PhotonCamera مو به مو می‌خورد؛ تبدیل TFLite از ONNX رسمی rembg،
  لایسنس Apache-2.0، فقط عملگرهای داخلی TFLite). ورودی float32 ‏[1,320,320,3]،
  خروجی float32 ‏[1,320,320,1]؛ پیش‌پردازش (تقسیم بر بزرگ‌ترین مقدار کانال +
  میانگین/انحراف ImageNet) و پس‌پردازش (min-max) دقیقاً قرارداد منتشرشده مدل است
  و در AiSegmenter با خودآزمایی شکل ورودی/خروجی در لود محافظت می‌شود.
- **تست عملکردی (نه فقط ساختاری):** هر دو مدل روی یک عکس محصول مصنوعی با
  حقیقت معلوم اجرا شدند — U2NetP: میانگین ماسک ۰٫۸۴۷ داخل سوژه در برابر ۰٫۰۰۲
  بیرون آن (جداسازی تمیز). **DeepLabV3 رد شد:** ۸۵٪ سوژه را پس‌زمینه تشخیص داد؛
  برای همین در v3.1 استفاده نشده است (بخش قدیمی این README که DeepLabV3 را مدل
  مناسب می‌دانست، با همین تست باطل شد).
- **امنیت/حریم خصوصی:** مدل و موتور کاملاً روی گوشی‌اند؛ عکس از گوشی خارج نمی‌شود.
  اگر فایل مدل خراب باشد، SHA-256 در اولین استفاده نمی‌خورد و موتور غیرفعال
  می‌شود (اپ به کلاسیک برمی‌گردد، کرش نمی‌کند).

## محدودیت شناخته‌شده: محصول سفید روی پس‌زمینه سفید
جداسازی کلاسیک بر اساس رنگ است؛ وقتی محصول و پس‌زمینه هر دو سفیدِ تقریباً یکسان‌اند (اختلاف رنگ زیر آستانه)، هیچ آستانه‌ای آن‌ها را جدا نمی‌کند. **موتور AI این را بهتر می‌کند** (مدل «شیء برجسته» را می‌شناسد، نه فقط اختلاف رنگ — پس اگر لبه یا سایه‌ای دیده شود، محصول سفید را هم پیدا می‌کند)، اما جادو نیست: اگر محصول واقعاً با پس‌زمینه یکی شده باشد، هیچ مدلی نمی‌تواند پیداش کند. در این حالت از **اصلاح لمسی** استفاده کنید (روی محصول بزنید) یا عکسی با پس‌زمینه کمی تیره‌تر بگیرید.

## آپلود و لینک مستقیم (تست‌شده با آپلود واقعی)
- uploadkon.ir: `POST https://uploadkon.ir/` با فیلدهای `submitr=1` و `ajax=1` و فایل با نام `file`.
- imgurl.ir: `POST https://imgurl.ir/upload.php` با فیلد `delete_at=1` و فایل با نام `userfile[]`.
- هیچ کلید API لازم نیست و هیچ قسمتی برای واردکردن کلید در اپ نیست.

## چه چیزی در این ماشین بررسی نشد (صادقانه)
- **روی این ماشین Android SDK نیست؛ پس پروژه کامپایل نشده و حجم دقیق APK اندازه‌گیری نشده است.** برآورد v3.1: پایه اپ ~۳٫۵ مگابایت + فایل `.so` موتور LiteRT ‏۴٫۳۲ مگابایت + مدل U2NetP ‏۴٫۵۶ مگابایت ≈ **۱۲٫۵ مگابایت** برای نسخه release (سقف ۱۰ مگابایت به انتخاب صاحب پروژه برداشته شد) — اما عدد دقیق فقط با بیلد شما مشخص می‌شود.
- استنتاج مدل ML روی گوشی واقعی اجرا نشده است (روی این ماشین با ران‌تایم Python معادل LiteRT اجرا و تایید شد؛ اجرای Kotlin روی گوشی با شماست).

## چک‌لیست شما بعد از بیلد
1. نسخه release را بگیرید و حجمش را بگویید (اگر release بالای ۱۰ مگ بود، بگویید debug بوده یا release).
2. جداسازی را روی چند عکس واقعی امتحان کنید؛ مخصوصاً محصول سفید روی سفید + اصلاح لمسی. زیر خروجی باید «هوش مصنوعی» نوشته شده باشد — اگر «کلاسیک»/«هوشمند» بود یعنی مدل لود نشده (لاگ‌کت را برای خطای AiSegmenter بفرستید).
3. اسلایدر مقایسه، خروجی شفاف، اندازه استوری و پردازش دسته‌ای را امتحان کنید.
4. لوگو را روی گوشی ببینید (آیکون لانچر + هدر داخل اپ).
5. **تم سایت (v3.2):** لینک یک سایت با برند مشخص را بدهید (مثلاً فروشگاه خودتان)؛ سه چیپ اصلی/فرعی/تاکید باید رنگ‌های واقعی همان سایت باشند و پس‌زمینه حالت برند باید گرادیان همان تم باشد — اگر رنگ‌ها اشتباه بودند، آدرس سایت و رنگ درست را بگویید تا امتیازدهی اصلاح شود.
6. اگر ارور سینک Gradle برای LiteRT داد (مثلاً میرور Aliyun نسخه را نداشت)، متن ارور را بفرستید — مخزن google() در settings هست و باید از آن بگیرد.
